# avr — брендбук

Всё, что входит в экосистему (avr music, avrtube, avrgram, avr studio, сайты на avthsr.space), выглядит и ведёт себя
одинаково. Основа бренда — **звезда** и слово **avr** с припиской продукта.

- Живой брендбук со всеми демо — [`brand/index.html`](index.html) (открыть через любой локальный сервер:
  `cd brand && python3 -m http.server`), он же опубликован артефактом.
- Дизайн-система для агентов (токены, компоненты с превью) — артефакт «avr» (ссылка в `docs/handoff/README.md`).
- Файлы — [`brand/assets/`](assets), генераторы — [`brand/tools/`](tools).

## 1. Суть

**Своё. Для своих.** Сервисы на своём сервере для владельца и 2–3 друзей: без рекламы, слежки и посторонних, вход по
приглашению. Ценности: своё (не исчезнет по чужому решению), для своих (закрытый круг), по-честному (оригиналы, без
тёмных паттернов), красиво и одинаково везде. Характер: тёплый, но спокойный (ночное море и мягкий свет звезды), живой
(формы перетекают, кнопки пружинят), свой (по-русски, на «вы», пасхалки вместо баннеров).

## 2. Семья и имена

| Продукт | Что | Знак |
|---|---|---|
| **avr** | экосистема целиком, сайты avthsr.space | звезда |
| **avr music** | музыка: сервер, сайт, Android, iPhone | звезда + две звуковые волны |
| **avrtube** | видео без рекламы, Android и iPhone | звезда + экран с Play |
| **avrgram** | Telegram для Android с защитой | звезда + сообщение |
| **avr studio** | витрина проектов (explore.avthsr.space) | звезда |

- Всегда строчными, даже в начале предложения.
- Приписка-слово — отдельно (`avr music`, `avr studio`), приписка-корень — слитно (`avrtube`, `avrgram`).
- Новый продукт: приписка по тому же правилу + атрибут по правилу из п. 4.
- old.avthsr.space — вне стиля (намеренный web 1.0); kgs и lks54 — не наши.

## 3. Звезда

- Четыре вогнутых луча в квадрате 100 × 100: `M50 2 C53 30 70 47 98 50 C70 53 53 70 50 98 C47 70 30 53 2 50 C30 47 47 30 50 2Z`
  (`STAR_PATH` в `avr.js`, `starPath` в `Brand.kt`).
- Градиент снизу слева вверх направо `#F2A5C3 → #5A4FC8`. Направление и цвета не меняем.
- Поле вокруг — четверть ширины звезды. Минимум 12 px; до 32 px — только звезда, без атрибутов.
- Версии: градиент (основная, на бирюзе и бумаге), туман `#D3E3E4`, бирюза `#0B4248`, белая — `assets/mark/`.
- Нельзя: растягивать, перекрашивать градиент, делать контуром, добавлять тень и объём, класть градиентную звезду на
  пёстрое фото (там белая), заменять символом ✦ или эмодзи.

## 4. Знаки продуктов (звезда + атрибут)

Атрибут — справа от звезды в поле 140 × 100: линии толщиной 6, скруглённые концы, **внешняя форма фиолетовая,
внутренняя — розовая**. Music — две волны, tube — экран с Play, gram — сообщение с двумя строками. avr и avr studio —
звезда без атрибута. Атрибут двигается только у своего продукта (волны — пока играет, экран — пока грузится видео,
строки — пока собеседник пишет). Файлы — `assets/signs/` (цветные, `-white`, `-teal`).

## 5. Надпись и сборки

- «avr» — Outfit Medium (500) цветом текста, приписка — Outfit Light (300) акцентом; разрядка −0.026 em; зазор у
  приписки-слова 0.14 em, у слитного имени — только смена веса и цвета.
- Цвета: на тёмном туман + розовый, на светлом бирюза + фиолетовый; одноцветно — белая или бирюзовая версия.
- Горизонтальная сборка: звезда 0.62 высоты шрифта по центру строчных, зазор 0.16 em — шапки, баннеры. Вертикальная:
  знак продукта над надписью — заставки, обложки, аватары.
- Файлы — кривыми, шрифт не нужен: `assets/wordmarks/`, `assets/lockups/` (`-dark`, `-light`, `-mono-white`,
  `-mono-teal`, `-stacked-*`). Код: `<span class="avr-word">avr<i>music</i></span>`, в Compose — `Wordmark`.
- Нельзя: заглавные, другой шрифт, один вес у обеих частей, один цвет у обеих частей, обводка.

## 6. Иконки

Бирюзовая плитка `#0B4248`, скругление 22.5 %, знак продукта по центру (со знаком — 68 % ширины, одна звезда — 56 %).
`assets/icons/<продукт>.svg`, PNG 1024 / 512 / 192 в `icons/png/`, адаптивный слой Android и монохромный — `-adaptive-*`.
Фавикон всех сайтов — звезда на плитке: `icons/avr.svg`, `favicon-16/32/48/180.png`.

## 7. Цвет

Две темы. **Тёмная** — родная: земля `#0B4248`, текст `#D3E3E4`, акцент `#F2A5C3`. **Светлая** — бумага `#E9EFEF`,
текст `#0B4248`, акцент `#5A4FC8`. Пропорции: 60 % земля, 30 % туман и поверхности, 10 % акценты.

| Роль | Тёмная | Светлая |
|---|---|---|
| `--primary` | `#F2A5C3` | `#5A4FC8` |
| `--primary-container` | `#5A4FC8` | `#E4E0FF` |
| `--secondary-container` | `#1E5B62` | `#CDE2E3` |
| `--tertiary` | `#C4BCFF` | `#A23F6E` |
| `--background` / `--surface` | `#0B4248` | `#E9EFEF` / `#EEF3F3` |
| `--on-surface` | `#D3E3E4` | `#0B4248` |
| `--on-surface-variant` | `#A9C4C6` | `#3E5F63` |
| `--surface-low … highest` | `#0E4A50 … #1A646C` | `#F3F7F7 … #D9E5E6` |

Фиолетовый на бирюзе (1.8 : 1) и розовый на бумаге (1.65 : 1) — никогда текстом. Глубина — тоном, не тенью.

## 8. Шрифт

Google Sans Flex (латиница) + Roboto Flex (кириллица), оси wght / wdth / ROND. Заголовки тяжёлые, широкие и круглые
(`wght 700–800, wdth 108–112, ROND 100`), текст обычный (`wght 400`). Классы: `.avr-display`, `.avr-headline`,
`.avr-title`, `.avr-title-sm`, `.avr-body`, `.avr-body-sm`, `.avr-label`, `.avr-kicker`. Outfit — только надпись avr.

## 9. Звезда в движении и фоне

| Эффект | Код (сайт) | Где и когда |
|---|---|---|
| Звёздное поле | `<section data-avr-starfield>` / `starfield(el, opts)` | герой, вход, заставка, пустые экраны, итоги; не под плотным текстом |
| Созвездие | `data-avr-starfield data-links` | всё про людей вместе: друзья, «слушать вместе», совпадение вкусов |
| Большая звезда | `.avr-bigstar` (+ `data-corner="tr\|tl\|br\|bl\|c"`) | за героем сайта, на обложках историй и релизов; один оборот за 140 с |
| Свечение | `.avr-glow` | за героем или плеером, одно на страницу |
| Лоадер | `<i class="avr-star avr-star-loader">` | ожидание дольше 0.4 с |
| Мерцание | `<i class="avr-star avr-twinkle" style="--d:.4s">` | рядом с новым и «живым»; не больше трёх на экран |
| Звезда приходит | `.avr-star-in` | первый момент страницы, заставка приложения |
| Искры | `sparkle(el)` / `data-avr-sparkle` | лайк, ачивка, принятое приглашение, угаданная мелодия; не чаще раза в секунду |
| Переход звездой | `starWipe({x, y}, go)` | только между продуктами avr и в большие моменты (итоги года, игра) |
| Звезда-форма | `data-avr-shape="star"`, `shapePath('star')`, `.avr-morph data-shape="star"` | награды, кнопка Play экосистемы |
| Маркер и разделитель | `ul.avr-stars`, `.avr-divider` | лендинги, «о проекте» |

Кривые: пружина `cubic-bezier(.34, 1.56, .64, 1)`, выход `cubic-bezier(.2, .8, .2, 1)`, перетекание формы
`cubic-bezier(.34, 1.45, .64, 1)`. Только `transform`, `opacity` и `d`; при «уменьшить движение» всё замирает
или просто проявляется. В Compose уже есть `BrandMark`, `BrandLoader`, `LiveMark`, `BrandIntro`; поле, искры и
переход — перенести (задача в `docs/handoff/README.md`).

## 10. Интерфейс

Material 3 Expressive в цветах avr. Формы: артист — `cookie9`, человек — `cookie12`, волна — `sunny`, акценты —
`clover`, награды — `star`, Play во время игры — `square`; все из 144 точек и перетекают друг в друга.

| Класс | Что это |
|---|---|
| `.avr-btn` (`.tonal`, `.outlined`, `.text`, `.big`) | кнопки-таблетки, углы сжимаются при наведении |
| `.avr-card` | карточка без теней; ссылка-карточка круглеет и приподнимается |
| `.avr-chip` (`aria-pressed`) | чипы-переключатели |
| `.avr-island` | плавающая навигация на телефоне (4 пункта, текущий — `aria-current`) |
| `.avr-morph` (`data-playing`, `data-shape`) | кнопка Play: печенье или звезда ↔ квадрат |
| `.avr-wavy` (`data-moving`, `--v`) | волнистая полоска прогресса |
| `.avr-reveal` | появление при прокрутке |

Иконки — Material Symbols Rounded (контур в покое, заливка у выбранного), сайт — `@m3e/icons/rounded`, приложение —
`composeResources/drawable/ic_*.xml`. Иллюстраций с персонажами нет: только звёзды и формы.

## 11. Голос

По-русски, на «вы», коротко и по-человечески: «Трек ещё скачивается — включу, как только будет готов», а не «Ошибка
404». Без канцелярита, восклицательных знаков и эмодзи. Кнопка — глагол. Буква ё, кавычки «ёлочки», длинное тире,
неразрывный пробел перед единицами.

## 12. Что куда когда

| Где | Что | Файл / код | Когда |
|---|---|---|---|
| Иконка приложения | знак продукта на плитке | `assets/icons/<продукт>.svg`, `icons/png/*` | всегда, с первой сборки |
| Заставка приложения | звезда приходит, кольца, надпись | `BrandIntro`, `.avr-star-in` | холодный запуск, 1.1 с |
| Вход и приглашение | звёздное поле + вертикальная сборка | `data-avr-starfield`, `lockups/*-stacked-*` | пока человек не вошёл |
| Шапка сайта | горизонтальная сборка | `lockups/<продукт>-dark\|light.svg` | всегда; на телефоне — одна звезда |
| Герой лендинга | звёздное поле или большая звезда + свечение | `data-avr-starfield` / `.avr-bigstar` + `.avr-glow` | первый экран, одно из двух |
| Загрузка | дышащая звезда | `.avr-star-loader`, `BrandLoader` | дольше 0.4 с |
| Пустое состояние | звезда 64–96 px + фраза + кнопка | `mark/star.svg` | пустая библиотека, нет результатов |
| Награда | искры | `sparkle()` | лайк, ачивка, приглашение, игра |
| Новое и живое | мерцающая звезда | `.avr-twinkle` | бейдж «новое», друг слушает сейчас |
| Люди вместе | созвездие | `data-links` | друзья, «слушать вместе» |
| Переход между продуктами | звезда растёт из точки | `starWipe()` | music ↔ tube, вход в итоги года |
| Истории, итоги, релизы | большая звезда + надпись | `.avr-bigstar`, `backgrounds/bigstar-*` | итоги, новости, заметки к релизам |
| Превью ссылки | 1200 × 630 | `social/og-<продукт>.png` в `og:image` | каждая страница сайта |
| Фавикон | звезда на плитке | `icons/avr.svg`, `favicon-*.png` | все сайты avr |
| Бот, канал, профиль | знак в круге | `social/avatar-<продукт>.png` | аватары ботов |
| Уведомления | одноцветный знак | `signs/*-white.svg`, `mark/star-white.svg` | строка состояния Android |
| GitHub | баннер, иконки | `social/github-banner.png` | README, релизы |

## 13. Порядок внедрения

1. Основа — брендбук, дизайн-система, `assets`, звезда в `avr.css`/`avr.js` (готово).
2. Сайты avthsr.space и explore: шапка, фавикон, превью ссылок, герой со звездой.
3. avr music: звёздное поле на входе и в тизере, искры, созвездие у друзей, аватар бота; эффекты — в Compose.
4. avrtube и 5. avrgram — со стилем avr с первого релиза.

## Подключение

```html
<link rel="stylesheet" href="/brand/avr.css">          <!-- шрифты рядом, в fonts/ -->
<script type="module" src="/brand/avr.js"></script>     <!-- формы, звезда, поле, искры, переход, тема -->
<html data-theme="dark">                                <!-- или "light"; без атрибута решает система -->
```

Пересобрать файлы после правки геометрии: `python3 brand/tools/build.py && node brand/tools/render.mjs`.
