# Сайты на avthsr.space

В репозитории лежит только то, что публично и не содержит секретов. Серверные части сайтов (бэкенд портфолио, его данные и
`.env`) здесь не хранятся.

| Сайт | Что это | Устройство |
|---|---|---|
| **avthsr.space** (и www) | визитка avr — слайдер: сервисы (music, tube, gram, портфолио), «о создателе» и проекты | статика из `sites/main/` (`node build.mjs`, проверка `node check.mjs`, выкладка `deploy.ps1`), стиль из `brand/` |
| **explore.avthsr.space** | «Stefan» — портфолио: бенто-плитки, лента постов, «сейчас слушаю» из avr music, терминал с пасхалками | React + Vite, Express на сервере за nginx; исходники в репозиторий не кладём (см. ниже) |
| **music.avthsr.space** | avr music | выкатывается из этого репозитория (`deploy.yml`) |
| **old.avthsr.space** | прошлая версия — намеренный web 1.0 | не переделываем |
| **kgs, lks54** | чужие проекты | не трогаем вообще |

Портфолио с 9 октября 2026 живёт на explore (раньше — на основном домене). `localStorage` привязан к адресу, поэтому прогресс
терминала у посетителей начался заново.

## Визитка (`sites/main/`)

- Страница — горизонтальный слайдер на `scroll-snap`: сервисы и проекты описаны данными в `site.js` (`SERVICES`, `SECTIONS`),
  новый продукт — одна запись.
- Эффекты — из `brand/avr.js` (звёздное поле, переход звездой, искры); тема и язык запоминаются в браузере.
- «Спокойный режим» (кнопка в шапке и автоопределение медленных устройств) убирает вращающиеся звёзды и звёздное поле.
- Статус сервисов («на связи») читается из `/status.json`, его раз в минуту пишет скрипт на сервере.
- Строгие заголовки (CSP, HSTS) задаёт nginx, поэтому на странице нет inline-скриптов: тема ставится из `theme-boot.js`.

## Пасхалки портфолио (их сохраняем при любых переделках)

**Маршруты:** `/`, `/about`, `/projects`, `/skills`, `/contact`, `/feed`, `/post/:id`, `/login`, `/settings`, скрытые
`/white-space` и `/black-space-2/*`.

**Терминал** (команды): `help`, `whoami`, `ls`, `cd`, `pwd`, `uname`, `clear`, `intro`, `about`, `projects`, `skills`,
`education`, `hardware`, `contact`, `feeds`, `fortune` (цитаты), `matrix` («Follow the white rabbit»), `meow` (мурчание
со звуком), `coffi`, `test`, `ri`, `friends`, `together`, `terminal-activity`, `login`, `sudo`, `rm`, `hack`, `exit`,
`blackspace` («REALITY BREACH DETECTED» → глитч → белое пространство), `unlock`, `kill-glitch`, `reset-count`,
`reset-terminal`. Терминал открывается на весь экран клавишей `` ` `` (Esc — закрыть).

**Состояние, которое терминал помнит** (`localStorage`): найденные секреты (`terminal.secretsFound` — из них в углу
рисуется созвездие), «уровень доверия», счётчик команд, журнал активности, статус виселицы, «открытие пустоты», первый
контакт, определённая ОС, серия неверных команд (после неё — глитч страницы), `seen_the_truth`, друзья терминала.
