# avr — стиль AVR ecosystem

Всё, что входит в экосистему (avr music, avrtube, avrgram, сайты на avthsr.space), выглядит и ведёт себя одинаково.
Живой образец — [`brand/index.html`](index.html) (открывается локально, переключатель светлой и тёмной темы).

## Подключение

**Сайт без сборки:**

```html
<link rel="stylesheet" href="/brand/avr.css">          <!-- шрифты рядом, в fonts/ -->
<script type="module" src="/brand/avr.js"></script>     <!-- формы, кнопка-морф, появление, тема -->
<html data-theme="dark">                                <!-- или "light"; без атрибута решает система -->
```

**Приложения** (Compose Multiplatform): цвета и формы — в `android/shared/.../ui/Brand.kt` и `Theme.kt`,
те же значения, что здесь.

## Цвета

Две схемы — тёмная (родная земля бренда: глубокая бирюза) и светлая (бумага). Роли — как в Material 3:

| Роль | Тёмная | Светлая |
|---|---|---|
| `--primary` | `#F2A5C3` розовый | `#5A4FC8` фиолетовый |
| `--primary-container` | `#5A4FC8` | `#E4E0FF` |
| `--secondary-container` | `#1E5B62` | `#CDE2E3` |
| `--tertiary` | `#C4BCFF` | `#A23F6E` |
| `--background` / `--surface` | `#0B4248` | `#E9EFEF` / `#EEF3F3` |
| `--on-surface` | `#D3E3E4` | `#0B4248` |
| `--on-surface-variant` | `#A9C4C6` | `#3E5F63` |
| `--surface-low … highest` | `#0E4A50 … #1A646C` | `#F3F7F7 … #D9E5E6` |

Звезда — градиент `#F2A5C3 → #5A4FC8` (`--avr-gradient`). Слово-знак: «avr» Outfit Medium цветом текста +
«music» (или имя продукта) Outfit Light акцентом: `<span class="avr-word">avr<i>tube</i></span>`.

## Шрифт

Google Sans Flex (латиница) + Roboto Flex (кириллица), переменные оси: вес, ширина, округлость.
Заголовки — тяжёлые, широкие и круглые (`wght 700–800, wdth 108–112, ROND 100`), текст — обычный (`wght 400`).
Классы: `.avr-display`, `.avr-headline`, `.avr-title`, `.avr-title-sm`, `.avr-body`, `.avr-body-sm`, `.avr-label`, `.avr-kicker`.

## Формы

Material 3 Expressive, одни и те же точки — любые две формы перетекают друг в друга:

- `cookie9` — артисты, кнопка Play на паузе;
- `cookie12` — люди и аватарки;
- `clover`, `sunny` — значки, акценты;
- `square` (скруглённый квадрат) — кнопка Play, пока играет.

`<div data-avr-shape="cookie12">` обрезает элемент; `shapePath(name)` из `avr.js` даёт SVG-путь.

## Движение

- Пружина с небольшим перелётом: `cubic-bezier(.34, 1.56, .64, 1)` — нажатия, смена формы, углы карточек.
- Плавный выход: `cubic-bezier(.2, .8, .2, 1)` — появление, сдвиги.
- Нажатие — сжатие до 0.88–0.96; наведение на карточку — углы круглее и подъём на 4 px.
- Только `transform` и `opacity`; при «уменьшить движение» всё замирает.

## Компоненты

| Класс | Что это |
|---|---|
| `.avr-btn` (`.tonal`, `.outlined`, `.text`, `.big`) | кнопки-«таблетки», углы сжимаются при наведении |
| `.avr-card` | карточка; ссылка-карточка меняет углы и приподнимается |
| `.avr-chip` (`aria-pressed`) | чипы-переключатели |
| `.avr-island` | плавающая навигация на телефоне (4 пункта, текущий — `aria-current`) |
| `.avr-morph` (`data-playing`) | кнопка Play: печенье ↔ квадрат |
| `.avr-wavy` (`data-moving`, `--v`) | волнистая полоска прогресса |
| `.avr-glow` | фирменное свечение за секцией |
| `.avr-reveal` | появление при прокрутке |

## Голос

По-русски, на «вы», коротко и по-человечески: «Трек ещё скачивается — включу, как только будет готов», а не
«Ошибка 404». Без канцелярита и без восклицательных знаков.
